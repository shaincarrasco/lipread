      About

      About LipRead

      LipRead estimates what people say from how their lips move. It is a free, open project, and the code is open source. Results are estimates and can be wrong.

      Privacy

      Videos are read on your device and are never uploaded. LipRead keeps no copy of your videos. The model, the app’s files, names you add and this setting are stored only in this browser.

      License

      The LipRead code is Apache-2.0. The lip-reading model is licensed for research and non-commercial use only, so do not use LipRead commercially.
